# User-facing feature assets

Screenshots and screen recordings of every user-facing feature of Humanity Labs. Each feature has its own folder:

```
<product>/<feature>/
├── screenshots/   still images, 2560 × 1600 PNG
├── recordings/    walkthrough videos, 1920 × 1200 MP4, each with a .jpg thumbnail
└── README.md      what the feature does, with its recordings and screenshots
```

The showcases: [feature walkthroughs](../../USER_FACING_WALKTHROUGHS.md) (videos) and [user-facing features](../../USER_FACING_FEATURES.md) (screenshots).
